# AI Car Loan Approval & Risk Agent

An English-only, browser-based prototype that demonstrates an applicant car-loan journey, deterministic risk assessment, loan-officer review, and complete audit history using synthetic data.

See the [frontend documentation](frontend/README.md) for accounts, routes, architecture, and backend integration guidance.

## Run locally

Open `frontend/index.html` through the VS Code Live Server extension. ES modules are used, so opening the file directly with a `file://` URL is not supported.
